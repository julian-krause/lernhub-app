# Klänge

Echte Aufnahmen statt Oszillator-Pieptöne. Alle Quellen stehen unter **CC0** (gemeinfrei), gefunden über Openverse.
Alle Dateien: WAV, mono, 44,1 kHz, Spitze −1 dBFS. Die Lautstärke regelt `KLAENGE` in `ui/js/effekte.js`.

| Datei | Moment | Bauplan |
|---|---|---|
| `auswahl.wav` | Option angetippt | Bubble-Pop, auf 90 ms geschnitten |
| `richtig.wav` | Prüffrage richtig | Kalimba G4, nach 85 ms D5 (Quinte aufwärts) |
| `serie.wav` | ab 3 richtig in Folge | Kalimba G4 H4 D5 G5 im Abstand von 70 ms |
| `falsch.wav` | Prüffrage falsch | Kalimba D4 → H3 (kleine Terz abwärts), Tiefpass 1,1–1,4 kHz |
| `geschafft.wav` | Quest, Tagesziel, Lektion fertig | Kalimba G3 D4 G4 H4 D5 G5 im Abstand von 75 ms, G5 klingt aus |
| `feier.wav` | Lektions-Feier (Overlay) | Harfen-Glissando aufwärts, 1,3 s |

Die Kalimba ist auf G-Dur-Pentatonik gestimmt (G A H D E). Deshalb klingt jede Kombination der Töne konsonant.
